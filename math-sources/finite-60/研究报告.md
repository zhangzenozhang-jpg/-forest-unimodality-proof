# 从50点向100点推进：已完成60点，100点仍有结构缺口

## 结论

本轮没有完成用户要求的全部100点。实际新增并完整认证的结论是：

\[
\boxed{|V(F)|\le60\Longrightarrow I_F(x)\text{ 单峰}}
\]

不限制最大度、分量数或孤立点；不是全序列对数凹。证明沿用最大独立集的精确分解、补充若干一般结构引理，再以完整有限有理代数证书闭合。不使用逐图穷举或森林目录。

| 范围 | 状态 |
|---|---|
| 所有森林，至多50点 | 原证明重新精确核验通过 |
| 所有森林，至多60点 | 本轮完整覆盖，两种不同整数算术核验通过 |
| 所有森林，至多100点 | 未完成，不应修改定理上限为100 |
| 原四类实变量约束，在55点参数处 | 有满足全部约束的严格凹谷有理数组 |
| 本轮增强实变量约束，在100点参数处 | 仍有满足全部约束的严格凹谷有理数组 |

上述数组不是图，更不是森林反例。它们证明的是指定放松模型信息不够，不是否定单峰猜想。

## 一、与原50点证明相比，新增了什么

固定最大独立集 \(I\)，补集 \(Y\)，写 \(a=|I|,v=|Y|,\delta=a-v\)。令 \(t_{j,m}\) 计数 \(Y\) 中大小为j、在I侧还有m个可用顶点的独立集。始终保留全部独立集，不改用最大扩张层。

### 1. 有利的最大独立集选择

本轮证明，可以选择I使
\[
e(F[Y])\le\max(0,\delta-1).
\]
证明基于收缩最大匹配后的二着色块翻转：一个无未匹配终端的颜色块可以翻转以减少补集边，故最小补集边数的选择使颜色块由未匹配顶点控制。它对任意规模成立，不要求知道具体树形。

### 2. 删除关系的双向约束

删除一个已选Y顶点至少释放一定数量的私人I邻点；最大独立数同时限制它至多释放多少。对阈值指示函数和正部函数使用这些上下界，得到相邻层可用顶点分布的双向线性控制。

### 3. 可用顶点均值不能与补集边数独立变化

若 \(M_r=\sum_m m t_{r,m}\)，实际补集边数
\[
e=\binom v2-\sum_m t_{2,m},
\]
通过离散凸性、森林总边数上界及三角形排除，得到 \(M_r\ge C_r^0+\beta_r e\)。正负系数按原式保留，避免各层各自取最坏边数。

### 4. 按同一边数联动补集各层

对任何v点e边森林G，证明
\[
\binom vr-e\binom{v-2}{r-2}\le i_r(G)
\le\binom{v-1}{r}+\binom{v-e-1}{r-1}.
\]
左边是边事件并集上界；右边是星加孤立点的上界，由叶删除归纳得到。把e与第2层的精确身份联系起来，再用凹函数弦界，得到整个模型中的线性层间约束。

这一项补齐了60点范围内最后的 \((n,a,k)=(60,33,19)\) 缺口。其中一份完整证书给出
\[
\Delta_{20}\le\frac{96885639}{100000000}\Delta_{19}-141686748,
\qquad\Delta_k=c_k-c_{k-1}.
\]
因而 \(\Delta_{19}\le0\) 后不可能有 \(\Delta_{20}>0\)。它对所有60点独立数33的森林同时成立，而不是具名例子的核验。

## 二、实际完成的证书覆盖

待处理参数不是图，而是
\[
2\le n\le60,\quad\lceil n/2\rceil\le a\le n-1,
\quad1\le k<\lfloor(2a+1)/3\rfloor.
\]
整个域有17100组。

| 方式 | 数量 |
|---|---:|
| 直接二项式/系数界 | 14523 |
| 一维有理数差分比较 | 670 |
| 有理线性证书 | 1907 |
| 合计 | 17100 |

线性证书共142017个非零行乘数，每份作用于一个包含相应真实森林的实变量区域，最多610个变量。它没有枚举变量取值或森林结构。

`verify.py` 重新生成全部参数域，用公分母整数运算逐份检查，拒绝漏项、重复、多余项及不合法权重。`verify_grid.py` 使用另一套加权行实现和有方向的整数舍入检查全部线性证书。两者已实际通过，详见两份audit JSON。

仍须准确定位证明形式：本轮保留了1907份有限线性证书，不是已经得到少数几个无表的统一闭式不等式。计算不承担森林清单的全称覆盖，但有限证书算术是证明的一部分。

## 三、为什么不能直接把60改为100

### 原模型已经在55点失效

原50点证明的四类约束在 \((n,a,k)=(55,30,18)\) 下，有一个非负有理数组满足全部1198条行约束，但其形式系数满足
\[
\Delta_{18}<-69000000,\qquad\Delta_{19}>74000.
\]
因此单纯延长原表、保持原实变量模型不变，不会覆盖全部100点。

### 增强模型在100点仍有严格反见证

`countermodel_100_55_31.json` 在 \((100,55,31)\) 下给出693个非零有理计数。对应完整扩展行域8356条约束全部精确成立，同时
\[
\boxed{\Delta_{31}<-2\times10^{18},\qquad
\Delta_{32}>3\times10^{17}.}
\]
该文件不是浮点可行点：所有数以公共整数分母和整数分子给出。`verify_countermodels.py` 独立生成应检查的全部行，检查每一条并重新计算差分，已实际通过。形成反见证的精确数组及审核不需要线性优化器或符号代数包。

### 能推出什么，不能推出什么

它表明：这些明确的非负实变量结构约束，允许一个在第31差分为负、随后变正的形式多项式。因此这些行的任何非负线性组合，都不能在该整个放松区域上证明无回升。

它不表明存在100点森林反例，不表明100点不能证明，不表明加入计数整数性或更多可实现性关系后仍失败，也不构成对所有结构方法的障碍。数组的系数为有理数，不能冒充某张图的独立系数。

## 四、仍缺少的数学信息

现有模型保留了单层总数、可用顶点的分布、部分相邻层删除信息及同一边数，但没有完整描述同一森林中全部删除关系能否同时实现。下一步实质目标是再取得此类一致性约束，或改变分解/无回升比较，使100点反见证被排除。

本轮还测试过双侧二分计数、固定补集边数分支以及其他约束，部分位置有额外证书，但没有形成全部100点的完整覆盖，故不计入正式结论。61点及以上的全范围也未据这些零散结果宣布完成。
