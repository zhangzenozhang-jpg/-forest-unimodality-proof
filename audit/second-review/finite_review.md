# 有限阶部分第二轮独立审查

审查日期：2026-09-26。审查对象：`outputs/JSP-000826_Tong_Zhang/paper/finite60.tex`、原始 `60点以内全森林单峰_接续证明.md` 以及 `verify.py` 的数学行、归一化和覆盖逻辑。此次按寻找反例与错误的方式重新核查，不以首轮“通过”作为数学前提。

## 结论

在有限阶部分未发现明确的数学缺口或论文翻译错误。其结论确实是 **所有至多 60 个顶点的有限简单森林**，包括孤立点、非连通森林和无边森林；不只是所枚举的若干图，也不局限于特定最大度。该结论依赖随附精确证书，而不是独立于证书的闭式证明。

这份结论仅覆盖有限阶部分；对大阶解析桥接、继承引理和全猜想的最终判断，应合并另一路独立审查。第二轮审查及小图测试均不等同于同行评审或形式化认证。

## 重点逐项核查

1. **最大独立集与匹配。** 逐叶递推给出 `a + v = n`，任一最大独立集必须包含全部未匹配点，并在每条固定最大匹配边中恰选一点。此处没有把“极大”误当成“最大”。分解 `I_F(z) = (1+z)^a + sum t_(j,m) z^j (1+z)^m` 对全部独立集计数，唯一性与 `j+m <= a` 均成立。

2. **稀疏补集选择。** 固定匹配收缩后仍是森林。标签相同的边恰有一个被选端点，标签不同的边在独立性下恰是补集内边。交换无终端单色块不会引入相邻被选点，并严格减少边界补集边。按原分量求和可得 `e(F[Y]) <= max(0, a-v-1)`，无需连通性假设。后续确实固定同一个独立集、同一个补集和同一个实际边数。

3. **私人邻点与双向删除。** 度数计数的方向正确：`p >= d-r+1`；最大性同时给出单坐标上界 `p_u <= d-r+1`。阶跃下界正确使用整数性，反向扩展下界采用全图边数上界，虽可能较弱但有效。凸函数最大化所用集中质量向量是放松域上的合法上界。

4. **均值约束。** 离散凸二项式函数在相邻整数 1、2 处的割线对整数域为下支撑。跨边数不超过 `n-1-e` 在非连通情形仍有效。补集内边两端各有非空且互不相交的原独立集邻域，因此扣除项中的 `a-2` 方向正确。保留共同的 `e` 再代入 `binom(v,2)-T_2`，得到论文及代码中一致的负号；未把可能为负的 beta 用错误方向替换。

5. **边数系数界。** 星加孤立点上界的叶删除差值为非负多项式；递推中指数的非负性已被处理。凹函数的弦给出下界，代回系数上界后得到 `D_0 T_r - G_r T_2` 的正确方向。`D_0=0` 的普通层质量界是有效的较弱替换。

6. **头尾与非单峰刻画。** 可添加点诱导森林的独立数至多 `a-k`，给出 `(k+1)c_(k+1) <= 2(a-k)c_k`。尾部起点 `floor((2a+1)/3)` 正确。此前的证书保证非正差分不能恢复为正，从而足以推出允许峰顶平台的单峰性；这个充分条件无需与所有非严格单峰序列等价。无边及空森林另行处理，参数域没有遗漏小阶边界。

7. **证书与原代码。** 逐条对照了所有全局有效行族及条件行。论文以 `x=t/W_j` 书写，主核验器在未加权计数坐标下实现，因此代码中等式乘子的 `eta/v` 与论文中的第一层质量等式一致。残差的每层非负最大值、右端项和非负乘子的方向正确。只有对应的 conditional 证书可以加入同索引 `Delta_k <= 0`。直接判据跳过的高层系数均为零；其覆盖不漏项。主核验器重新产生全参数域并要求证书集合恰好匹配剩余参数，不是仅遍历作者列出的“成功案例”。

8. **论文表述。** 英文有限阶部分忠实呈现原证明，并补足了原稿一些压缩步骤；关键参数、覆盖数、例子和证书哈希与既有精确复算记录一致。100 点反见证明确限定为实变量放松中的点，未称作森林反例。

## 本轮新增的独立小规模检验

新增 `finite_exhaustive.py` 使用 Python 标准库自行生成根树、按最小根表示去重为无根树，再生成树分量的无序多重集合。它不使用原包的图目录或图生成程序。根树/无根树数量校验通过。

对 **1 至 10 点的全部 637 个无标号森林**，程序独立枚举全部顶点子集以求真实独立集，计算真实最大独立数，在全部最大独立集中选择补集边数最小者，然后：

- 验证稀疏补集引理；
- 重建全部真实 `t_(j,m)` 并检验多项式精确分解；
- 检验路径下界和普适尾部不等式；
- 将真实计数代入主核验器全部有效结构行域，而不只代入证书使用的行。

结果为 **PASS，45,529 条结构行检查全部成立**。每阶森林数为 `1, 2, 3, 6, 10, 20, 37, 76, 153, 329`。原始结果见 `finite_exhaustive_results.json`。该检验的作用是寻找结构引理或代码符号的反例；全称结论仍依靠上面的数学证明和 60 点完整有理证书，不以小图测试代替证明。

脚本随后增加了可移植核验器定位、`--verifier` 和 `--output` 参数。默认仅打印结果；缺少开发目录时，从发布包的输入 ZIP 原样提取核验器到临时目录。模拟发布目录的实际回退运行仍得 **637 / 45,529 / PASS**，见 `finite_portability_results.json`；命令说明见同目录 `README.md`。
