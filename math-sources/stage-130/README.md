# 森林单峰研究接续包：170 → 130

日期：2026-09-25。

在输入包明确声明的结构前提下，本包证明所有有限简单森林的独立多项式在顶点数n≥130时系数单峰。允许不连通、最大度不限。新增有限范围为130≤n≤169；170以上继承冻结输入。没有统一补齐n<130。

## 运行

```bash
python -S check_release.py
python -S replay.py
```

前者仅验证文件与记录完整性，后者重新计算整个数学证书链。验证只用Python标准库；`-S`关闭环境预载，`-O`会被拒绝。沿用旧包的运行条件，建议使用Python 3.10或更新版本。

默认重放170→350→500→900全部旧依赖，再独立重构36份新独立支撑源项、92份新选集方差证书，检查243份新核、连续覆盖与身份诊断。不需要联网，也不调用NumPy、SciPy或数值优化器。

```bash
python -S replay.py --skip-prior
```

这个选项明确不重新计算旧链；仍验证冻结输入哈希并检查全部新证书。其输出不会冒充默认完整重放。

```bash
python -S negative_tests_next.py
python -S smoke_test.py
```

第一条验证故意破坏的输入被拒绝。第二条检查全部新源项、三份代表性新核和完整几何覆盖，但不重放旧链或所有新核，因此只是移址/安装检查。

## 主要文件

- `PROOF_ZH.md`：完整接续论证、源项新引理、连续域处理和依赖边界。
- `NEXT_ROUND.md`：从130继续的具体入口及129候选的限制。
- `bridge_certificates.json.gz`、`coverage_next.json`：243份精确核证书和148层连续覆盖。
- `sources/`：36份独立支撑源项和92份选集方差证书。
- `audit/`：本轮默认完整重放、拒绝测试与移址检查结果。
- `inputs/`：原始170ZIP，未修改；解包与核对由代码自动完成。
- `frontier/`：明确不构成定理的更低门槛候选。
- `discovery/`：可选的候选搜索工具；发现可以用SciPy，接受不使用它。

新核累计检查7,394,490个整数端点状态和165,240个完整实半轴，非枚举森林数。合并558份旧170核后共有801个有限核矩形。最小归一化新预算约0.00016566785596988035，其尺度为80。

本包是带明确继承结构前提的研究证明与精确算术证书，不声称已在证明助手中形式化全部理论、不声称公开最优阈值，也不把负的候选预算当作森林反例。
