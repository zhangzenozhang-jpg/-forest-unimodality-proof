# 森林独立序列研究：99 → 80 审计接续包

2026-09-25。

在原包明确列出的结构前提下，本包证明所有顶点数n≥80的有限简单森林，其独立多项式系数序列单峰。允许不连通，最大度不限。新增有限范围为80≤n≤98；99以上继承冻结输入。尚未统一证明n<80。

## 运行

```bash
python -S check_release.py
python -S replay.py
```

第一条只检查完整性和记录，不是数学重放。第二条默认递归重跑99→130→170→350→500→900，再独立重构全部新源项、均值归纳、新核和连续覆盖。验证只需Python标准库；建议Python3.10或更新版本，不联网、不调用数值优化器。禁止`-O`。

```bash
python -S replay.py --skip-prior
```

该选项明确不重新计算旧链，仍检查冻结输入哈希和所有新内容。发行审计中的旧链与新段分别运行，报告保留两个调用，不冒充一次默认完整调用。

源项检验默认使用3个标准库工作进程；可用`FOREST_CHECK_WORKERS=1`单进程验证。不同进程数不改变数学判定。

## 文件

`PROOF_ZH.md`为完整论证，包括消息相关精确零和项、对数方差修正、106点均值归纳、有限状态域与连续拼接。`NEXT_ROUND.md`标明如何继续，以及负N修正不能错误复用的限制。

`certificates.json.gz`保存236份精确核，`coverage.json`保存154层连续覆盖。`selectors/`、`flow_selectors/`、`log_selectors/`合计65份全规模方差证书。`density_certificates.json`保存106个活动度点的归纳数据。`audit/`保存实际重放、拒绝和移址记录。

`inputs/`保留原始99ZIP字节。首次运行自动安全解包并递归核对冻结依赖；`work/`是临时运行输出，不进入发行清单。`frontier/`中的75/70候选不是定理或反例。`discovery/`仅用于可选候选生成，不被接受重放调用。

## 范围与关键数字

新核37份左核、129份中央核、70份右核；全部43个父活动度区间无缝覆盖。与989份继承有限核合并，共1225个矩形，再接旧大m核预算。

新核累计2,523,312次整数端点状态检查和93,456次完整实半轴检查。这些不是枚举森林数。最小归一化预算约0.00004211246122361473，对应尺度38；各证书尺度不同。

本包是明确保留继承结构前提的研究证明与精确算术证书，不是整个理论的证明助手形式化，不主张公开最优阈值或所有n已解决。
