# 森林独立序列：完整500接续包

**正式完整门槛：n≥500。** n是顶点数。29个连续活动度区间覆盖[1/3,9/4]，按左上升、中央曲率、右下降拼接。新预算直接覆盖全部n≥500，不以原n≥900单峰定理为前提。

900→500减少44.44%，不是十倍下降。本包没有证明n<500的一般情形，没有扩大森林目录或小端九秩前缀，也不声称全序列对数凹或正式机器证明。

## 新方法

异质非负源项方差使用 AΣa_v²+CΣπ_va_v²，沿活动度下降路径保留真实占据均值。近对称Bernoulli的Gaussian模长界延伸至整个周期。中央曲率使用较近的Hermite接触点，并由真实下尾概率支付非二次剩余。相邻方向使用一个联合质量—有符号梯度下包络，保留零均值的一阶抵消。

这些新公式有完整连续域证明。472个源项概率区间和209个方向下包络矩形是固定低维标量证书，不是这些数量的森林。曲率剩余在40个固定节点上取有向界，区间之间由已证明的单调性覆盖。

使用Python标准库，必须保留断言，不要使用 `python -O`。


所有新计算在 `work/clean_replay_...` 的隔离目录中进行，固定有理参数不会被浮点寻优替换。默认入口不导入SciPy、NumPy或GMP。候选搜索函数虽然保留在部分源文件中，但不由复算入口调用。

首次运行在 `work/input/` 解开原始900ZIP；源代码和固定参数再按 `input_fingerprints.json`核对。不要并发启动多个首次解压进程。原ZIP的字节和SHA256固定，不以修改过的旧工作目录充作原输入。
