# 60点全森林证明与100点结构放松缺口

**本包不包含全部100点的证明。** 完整闭合的上界是60；两份严格凹谷见证只反驳指定的非负实变量放松，不反驳森林单峰猜想。

先读 `研究报告.md`，完整推导见 `60点以内全森林单峰_接续证明.md`。

## 核验

在此目录运行，使用Python 3.10或更高版本的标准库即可：

```bash
python verify.py
python verify_grid.py
python verify_countermodels.py
```

不要使用 `python -O`，核验器会拒绝关闭assert检查的运行方式。

第一项重新生成并核验全部17100组参数，用公分母整数算术；第二项对1907份线性证书使用另一种有方向的整数舍入；第三项重新生成两个反见证各自的完整行域，检查非负性、总质量、全部整数不等式及严格差分。

程序不导入优化器，不信任浮点容差，不枚举森林。`certificates.json` 中未存的参数由直接公式核验；核验器拒绝漏项、重复项、多余项、非法行和负不等式乘数。

审核程序会覆写相应audit JSON，其中运行时间会变动。`SHA256SUMS.txt` 是本次打包文件的哈希记录，审核后时间字段的变化不改变数学证书。

## 证明形式

这是一份含有限有理证书的结构证明，不是逐图穷举，但也不是无表的短闭式证明。全称覆盖由森林结构引理、系数分解和标量参数域承担。1907份线性证书是最终论证的一部分。

所有规模、最大度和连通性条件详见正文。n≤60单峰不是全序列对数凹。精确算术复核不代替对结构引理的独立数学审查。
