# 森林独立序列接续包：130 → 99

2026-09-25。

在原包明确列出的结构前提下，本包证明所有n≥99的有限简单森林独立多项式系数单峰，允许不连通和无界最大度。新增范围99≤n≤129；130以上继承原始输入。没有统一证明n<99。

门槛减少31，约23.85%；相对于最初350累计减少251，约71.71%。这里n是顶点数，不是系数秩。

## 复算

```bash
python -S check_release.py
python -S replay.py
```

第一条仅检查文件和记录完整性，不是数学重放。第二条默认先完整重跑130→170→350→500→900链，再独立重构新增源项、重算全部188份新核和连续覆盖。接受只需Python标准库，不联网，不调用NumPy或SciPy。建议Python 3.10或以上；`-S`关闭环境预载，`-O`会被拒绝。

```bash
python -S replay.py --skip-prior
python -S negative_tests.py
python -S smoke_test.py
```

`--skip-prior`显式保留旧链而不重新计算它，仍核对冻结输入哈希并重算全部新内容。negative_tests检查故意破坏的输入被拒绝。smoke_test检查所有新源项、三个代表性核和完整覆盖，不等于全部核及旧链重放。

本次实际审计分别记录成功的完整旧130链重放和成功的新段重放。首次默认调用在新覆盖表尚未构建完成时正确拒绝；这次拒绝没有被记为成功。详见audit/REPLAY_NOTE.md。

## 内容

`PROOF_ZH.md`给出完整新论证，包括共同条件噪声的四分之一协方差身份、异质标记源项沿倾斜路径的合法使用、有限路径边界增益以及允许三类核混用的无谷底引理。`NEXT_ROUND.md`记录继续下降的具体入口与98候选的限制。

`certificates.json.gz`保存188份新核；`coverage.json`保存148个连续q层上的完整实数m覆盖。与243份旧130核、558份旧170核合并后，共989个有限核矩形，覆盖全部43个父活动度区间。

`sources/`保存31份独立集标记源项及3份全均值源项。`audit/`保存独立重构、核检查、拒绝测试和移址结果。`inputs/`保留用户原始130 ZIP字节，首次运行自动解包并核对。

`frontier/`只含未认证的98局部候选，不能作为定理或反例。`discovery/`是可选搜索工具，可使用SciPy，但不会被默认接受路径调用，也不自动替换固定证书。

新核共有30份左核、98份中央核、60份右核；28份使用的核不同于原父行指定角色。累计检查3,397,160个整数端点状态和97,760个完整实半轴。这些不是枚举森林的数量。

最小归一化预算约0.00039739781690382845，对应S=49；原核下界须除以49。证明助手形式化、所有n的统一结论和公开最优门槛均不在本包声明范围内。
