在输入80包明确声明的结构前提下，本包证明：所有顶点数n≥59的有限简单森林，其独立多项式系数序列单峰。不限制连通性或最大度。新增部分为59≤n≤79；n≥80继承原始输入。

**已降至60以下。没有统一证明所有n，也没有证明全序列对数凹。**

本轮主要工具是最大占据权独立集的叶子性质、其补集中的匹配下界，以及精确的条件配置消去身份。它们生成新的M与Y联合计数约束，而不只是改善一个M尾部常数。

## 复算

使用Python 3.10或更新版本；证明接受只需标准库，不联网，不调用数值优化器。

```bash
python -S check_release.py
python -S replay.py
```

第一条只检查文件完整性和记录；第二条默认先重放完整80→99→130→170→350→500→900链，再重算全部新源项、新核、独立计数和连续覆盖。不要使用`-O`，程序会主动拒绝。

```bash
python -S replay.py --skip-prior
```

这个选项仅跳过旧链重算；仍验证原始ZIP与解包文件哈希，独立检查所有新证明。输出明确记录未在该次调用中重跑旧链。

```bash
python -S negative_tests.py
python -S smoke_test.py
```

前者检查故意破坏的输入被拒绝；后者用于移址检查，覆盖全部四份新源项、三份代表性核和完整连续几何，不替代全表重放。
