# 森林独立序列：350 → 170 审计接续包

2026-09-25。

## 结果

在用户输入350包列明的组合首尾、全规模活动度2均值、已发表活动度1均值及方差源项依赖成立的前提下，本包证明：**所有顶点数n≥170的有限简单森林，其独立多项式系数序列单峰。**

新增证明覆盖170≤n≤349，不限制连通性或最大度；350以上冻结复用。阈值减少180，下降约51.43%。**没有统一证明n<170，没有证明全序列对数凹。**

新方法直接认证条件二项式核，用Laplace矩构造点态有理下界，避免在新增有限段把主核替换为高斯再支付统一近似误差。558份证书、43个活动度父区间、130个q层连续覆盖；m不是整数网格。详细证明与全称量词见`PROOF_ZH.md`。

## 运行

使用Python 3.9或以上，保留断言，不要加`-O`。证明重放只需标准库，不联网、不调用数值优化器。

```bash
python check_release.py
python replay.py
```

第一条检查哈希和记录完整性；**不是**数学重放。第二条默认重放350→500→900冻结依赖链，再重算全部新证书、无限j半轴、q和m连续覆盖及补充诊断。

已经审查过旧依赖时可显式只重放新段：

```bash
python replay.py --skip-prior
```

该选项仍检查冻结输入的文件哈希、43个旧m阈值及全部新证书的参数来源，但不重算旧链证书。

输出写入`work/latest_replay_summary.json`及`work/latest_certificate_checks.json`。`work/`是临时运行目录，不属于发行文件清单。默认首次使用会从保留的原始ZIP安全解包依赖。
